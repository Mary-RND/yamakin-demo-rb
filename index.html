Три находки для решения о полном проекте

1. Поле прямых конкурентов узкое. В нише универсального светоотверждаемого композита частного сегмента РБ работают три сильных бренда (Kulzer, Tokuyama, Shofu). Формат «один оттенок» в реестре РБ представлен минимально: по поиску реестра заявлено лишь одно зарегистрированное предложение (OMNICHROMA, Tokuyama) — прямых сопоставимых продуктов мало, позиционирование A•UNO дифференцировано и защищено.

2. Каналы концентрированы и просчитываются. Основные наблюдаемые каналы — 4–6 белорусских специализированных игроков и маркетплейсы. Ниша (96 действующих лицензий со «стоматолог» в наименовании держателя) физически доступна для прямых контактов на полном этапе. Получение полного списка адресов клиник — задача полного проекта (адреса в публичном API ЕРЛ закрыты — это подтверждено технически).

3. Часть заявленного конкурентов не доходит до продажи. BEAUTIFIL II: зарегистрирован, выставлен в каталогах, но в продаже не подтверждён. Charisma Diamond One (новое поколение линейки Kulzer) в РБ не зарегистрирован — продавать его здесь будет нельзя до получения РУ. Полный проект уточнит эти статусы до уровня «официальный представитель / действующий продавец / партнёр» по каждому звену.

Мост к полному проекту (этапы 1–3 полного проекта засчитываются за счёт демо-среза)

Этап 1 (реестр РУ): закрыт на 100% — 3 слота с РУ + эталон. Этап 2 (каналы): закрыт на демо-уровне — 24 источника с URL и датами обращения; в полном проекте расширяется до 25–40 брендов и выгрузки дилерских списков. Этап 3 (статусы игроков): каркас собран — 3 связки «импортёр/дистрибьютор/партнёр» идентифицированы по публичным источникам; в полном проекте уточняется по сайтам изготовителей и переговорным рекомендациям.

Итог полного этапа: реестр 25–40 брендов + карта каналов + расчёт объёма (2 модели) + статус каждого звена — по этой же структуре. Адаптация методики — по запросу до старта.

Категории подтверждённости: A — государственные реестры и документы; B — открытые источники, подтверждённые не менее чем дважды, с URL и датой обращения; C — расчётные оценки с допущениями. Полный реестр и материалы следа (Демо_выписка_РУ_День1.txt, Демо_каналы_День2.txt, Демо_лицензии_96_raw.json) прилагаются.
Контроль доступа — лёгкая защита демо-материалов (client-side), не заменяет официальную передачу по e-mail/каналу заказчика.
